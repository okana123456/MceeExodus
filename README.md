# MC Exodus website

Phase 1 of the official MC Exodus website, built for PHP hosting in cPanel.

## Deployment

The production website deploys to:

`/home/rudderdatanalyti/mcexodus.com/`

Use GitHub Desktop to commit and push, then use cPanel Git Version Control to update from remote and deploy the HEAD commit.

## Private configuration

1. Copy `includes/config.local.example.php` to `includes/config.local.php` on the server and set the booking notification email.
2. Copy `admin/config.example.php` to `admin/config.php` on the server.
3. Replace the example value with a password hash generated by PHP's `password_hash()` function.
4. Never commit either private configuration file.

## Search visibility

The production website is indexable at `https://mcexodus.com`. Its sitemap is available at `https://mcexodus.com/sitemap.xml` and private utility folders are excluded in `robots.txt`.
